# Category and owner access

Category navigation has a sliding glass indicator for pointer, keyboard focus, and category selection. Featured project headline and CTA have been removed. Existing role photos temporarily fill the BTS hero. Add `categoryBts` to content.js with arrays of asset paths keyed by director, dop, producer, videographer when the BTS sequences arrive. The explanatory sentence below the shelves is removed.

The former browser editor is retired. Owner login opens GitHub's file editor for content.js in the private arynoorworks/ary-noor-works repository. Authentication and write access are enforced by GitHub. This is not an integrated visual CMS. GitHub changes do not automatically update this local preview. No credentials are embedded in website files. The existing GitHub snapshot has not been updated by this local design revision.

Current local preview: run `python3 -m http.server 4174 --bind 127.0.0.1` in this folder and open http://localhost:4174/.
