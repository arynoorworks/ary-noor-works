# Film-led home

Reference observed: A24 homepage, 14 November 2026. Borrowed the interaction pattern of vertically sequenced full-bleed film panels and large overlaid titles. No A24 media, code, logo, or copy is used.

Home order is now welcome ANW opening, selected film panels, profile, role categories, and contact. Scroll to discover targets the film sequence. Each panel offers the existing fullscreen preview, its detail via the title, and a category link. Video fields are still empty where no file has been supplied. Profile, category catalogs, logos, contact form, and project data are preserved.

Default featured IDs: let-it-stay-with-you, marongan, maafkan-aku-shifu. Set featuredProjectIds in content.js to change the selection or order. The new styling is in home-films.css. Ordinary document scrolling is used, without scroll trapping or a carousel dependency. Mobile sizes and reduced-motion styles included.
