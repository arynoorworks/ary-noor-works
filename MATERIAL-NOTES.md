# Pembaruan materi — Draft 0.2

Materi dari PDF portfolio 2024 yang diberikan pengguna: enam proyek, enam still, portrait, profil, email, nomor telepon, Instagram, logo ANW, dan palet biru (#0d1b2a, #1b263b, #2e4057, #3a506b, #5a768d).

Logo `assets/logo-anw-original.png` adalah image yang diekstrak utuh dari halaman 8, bukan gambar ulang. Pixel, transparansi, warna, ruang kosong, dan rasio gambar asli dipertahankan. Diletakkan pada bidang putih agar tulisan gelap asli terbaca. Tidak ada filter CSS atau crop pada logo. SHA256: `38be2875a8029f23593a7986e51be0ead51acac7ac76dc6b2c708bd0f1208397`.

Lima tautan tontonan berasal dari anotasi PDF dan dipasang sebagai tautan eksternal; izin akses/ketersediaan terkini belum diperiksa. Posisi anotasi digunakan untuk mencocokkan tautan dengan film yang benar. Film When the Poor Boy Was Dreaming tidak memiliki link pada sumber; status rilis terkini tetap belum dikonfirmasi. Tidak ada klaim penghargaan atau tambahan kredit yang direka.

Deskripsi proyek dan catatan craft diparafrasakan dalam bahasa Indonesia. Beberapa film tidak memiliki sinopsis dalam PDF sehingga slot sinopsis tetap ditandai belum lengkap. Informasi mahasiswa tingkat empat tidak dijadikan klaim status terkini. Foto-foto film tidak direkayasa atau diwarnai ulang; CSS object-fit pada kartu hanya menyesuaikan bidang preview, sedangkan galeri menampilkan rasio file asli.

Editor sekarang menyediakan URL tontonan eksternal, portrait, dan telepon. Draft lokal dari versi 0.1 diabaikan saat membuka versi materi ini agar placeholder lama tidak menimpa enam karya. Backup lama tetap dapat diimpor secara sengaja.

Website masih preview lokal, belum dikirim ke GitHub atau Cloudflare. Nomor/email dari PDF digunakan untuk draft sesuai permintaan; cek kembali kontak dan hak penayangan sebelum publikasi final.
