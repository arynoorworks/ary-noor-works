# Draft 0.4

Empat foto kategori dipisahkan dari screenshot pengguna, tanpa area label putih. Pemetaan mengikuti label sumber: foto kiri pertama untuk Director of Photography, foto kedua Director, foto ketiga Producer, foto keempat Videographer. File ada di assets/category-*.png; path dapat diganti melalui objek categoryPhotos di content.js.

Foto profil rounded rectangle dan biografi dipindah ke hero. Tidak ada lagi profil yang diulang di bawah hero. Mobile menumpuk tagline, foto, lalu biografi. Logo menggunakan alpha dari file asli sebagai CSS mask dengan gradient glass; bentuk dan proporsi asli dipertahankan tanpa kotak. Tulisan tambahan ARY NOOR / FILMMAKER dihapus; tulisan kecil yang merupakan bagian dari aset logo asli tetap dipertahankan.

Panduan ini menggantikan susunan hero dan ikon kategori pada versi 0.3. Materi proyek, kategori peran, editor, serta langkah publikasi gratis tetap tersedia.
