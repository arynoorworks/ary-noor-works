# ARY NOOR WORKS — publication snapshot, 14 November 2026

This is a buildless static website. No package installation, database, API key, or environment variable is required.

## Run locally

From the extracted project folder, run `python3 -m http.server 4174`, then open http://localhost:4174/.

## Edit projects

Edit `content.js` and place replacement media in `assets/`. The owner entry is `/admin/`; editing is authenticated by GitHub, not by a password embedded in this website. Contact inquiries open WhatsApp for the visitor to review and send. Nothing is sent automatically.

## Cloudflare Pages

Connect the `arynoorworks/ary-noor-works` repository, branch `main`. Framework: None. Build command: leave empty. Output directory: `/` (repository root). No environment variables are needed. The website uses hash routes, so category links work on static hosting.

## Preservation

The dated ZIP preserves the current implementation and all assets. Original working files are kept in place. Development screenshots and processing tools are included in the preservation archive, but temporary processing outputs are not deployed.

Never add credentials, `.env` files, tokens, or private account exports to the repository.
